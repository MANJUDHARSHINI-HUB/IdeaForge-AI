PROJECT IDEA 1

Title:
AI-Powered Student Project Recommendation System

Category:
Generative AI, Education, NLP

Difficulty:
Intermediate

Description:
An AI system that recommends suitable final-year project ideas to college students based on their skills, interests, preferred difficulty level, and project requirements.

Technologies:
Python, Streamlit, NLP, Generative AI, RAG, ChromaDB, Ollama

AI Components:
Embeddings, semantic search, Retrieval-Augmented Generation, Large Language Model

Suitable Skills:
Python, NLP, Machine Learning, Generative AI

Suitable Interests:
Education, Chatbots, Generative AI, Recommendation Systems

Project Scope:
The system can collect student information, retrieve relevant project knowledge, generate project recommendations, explain why each project is suitable, and provide a final recommendation.
